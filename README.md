# 🧾 Finanzas Personales - App de Escritorio

Aplicación de escritorio desarrollada en Python con PyQt5 y SQLite para el registro y control de finanzas personales. Permite ingresar y visualizar ingresos y egresos, con una estructura preparada para futuras mejoras como análisis visual, dashboards y reportes.

---

## ⚙️ Tecnologías utilizadas

- **Python 3**
- **PyQt5** – Interfaz gráfica de usuario
- **SQLite3** – Base de datos local
- **QStackedWidget** – Navegación entre páginas

---

## 🧠 Funcionalidades actuales

- Registro de ingresos y egresos
- Almacenamiento persistente en SQLite
- Interfaz gráfica modular y escalable
- Navegación tipo “pestañas” usando `QStackedWidget`
